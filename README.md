# 골목의 문장

한국 골목을 1인칭으로 산책하며 낙서와 전단지에 남겨진 20개의 문장을 수집하는 웹사이트입니다.

## 실행

`index.html`을 Chrome, Edge 또는 Safari에서 열어주세요. 별도 설치나 빌드는 필요하지 않습니다. WebGL을 지원하는 브라우저가 필요합니다.

골목이 브라우저 화면 전체를 채우며, 문장집·수집 현황·이동 버튼은 게임 화면 위에 표시됩니다.

## 산책 방법

- W / S 또는 위 / 아래 방향키: 앞뒤로 걷기
- A / D: 좌우로 걷기
- Shift + W 또는 Shift + 위 방향키: 빠르게 앞으로 걷기 (약 1.8배 속도)
- 왼쪽 / 오른쪽 방향키: 시선 회전
- 화면을 누른 채 드래그: 주위 둘러보기
- 골목 벽의 문장을 클릭 / 터치: 문장집에 즉시 수집
- E 또는 ‘클릭해서 문장 수집’: 가까이 있는 문장 수집
- 수집한 문장을 다시 클릭: 자세히 읽기
- 휴대폰: 골목 화면 아래의 화살표로 이동
- ‘나의 문장집’: 수집한 문장 보기 및 영수증 모양 PDF 내려받기
- 음표 버튼: 골목의 바람 소리와 발자국 소리 켜기 / 끄기
- ‘처음으로’ 버튼: 수집한 문장과 이동 거리를 초기화하고 시작 화면으로 돌아가기
- 오른쪽 위 약도: 두 번 꺾이는 골목 안에서 현재 위치 확인

문장집은 현재 브라우저의 로컬 저장소에 보관됩니다. 브라우저 설정 또는 비공개 모드에 따라 저장이 유지되지 않을 수 있습니다. 골목, 구름이 흐르는 하늘, 걸어 다니는 길고양이 두 마리, 걷고 바닥을 쪼는 비둘기 일곱 마리와 골목 소품은 자체 생성합니다. 전체 UI와 벽의 문장에 로컬 Min Sans 폰트를 사용하므로 외부 글꼴 연결이 필요하지 않습니다. 폰트 라이선스는 assets/MinSans-LICENSE.txt에 있습니다.

문구점의 공책 진열대, 미용실의 거울과 의자, 마트의 상품 선반과 과일 상자로 가게를 구분합니다. 간판에는 글자를 사용하지 않습니다. 골목 둘레에는 연속된 건물을 배치해 바깥 공간이 보이는 틈을 막았습니다.

건물과 소품에는 검은 윤곽선과 옅은 회색 명암, 빗금을 사용합니다. 하늘·동물·조작 UI도 무채색이며, 골목에서 수집하는 20개의 문장 종이에만 색을 남겼습니다.

## 파일

- index.html: 한국어 화면 및 대화상자
- style.css: 반응형 디자인
- app.js: 외부 라이브러리 없는 WebGL 골목, 이동 및 문장집
- receipt.js: 한글 영수증 디자인과 브라우저 내 PDF 생성

첫 골목에 8개, 첫 번째 굽이 뒤의 골목에 6개, 가장 안쪽 골목에 6개의 문장이 배치되어 있습니다. 기존에 수집한 문장은 유지됩니다.

문장집의 ‘영수증 PDF 내려받기’ 버튼은 현재 수집한 문장만 수집 순서대로 담아 80mm 폭의 영수증 PDF를 저장합니다. 문장 개수에 맞춰 종이 길이가 늘어나며, Min Sans 글꼴로 출력합니다. 외부 서버에 문장을 보내지 않습니다.

발자국 소리는 실제 이동 거리에 맞춰 재생되며, Shift로 빠르게 걸으면 발걸음 간격도 짧아집니다. 멈추거나 벽에 막히거나 문장집을 열면 새 발자국 소리는 나지 않습니다. 오른쪽 위 음표 버튼으로 바람 소리와 함께 켜고 끕니다.

기본 걸음은 여유 있는 속도이며, 발자국은 약 0.55초 간격으로 작게 재생됩니다. 고양이 약 2.2m 안으로 다가가면 조용한 야옹 소리가 한 번 나며, 곁에 머물러도 반복되지 않습니다. 약 3.4m 밖으로 멀어졌다 다시 다가와야 반응하고, 같은 고양이의 울음에는 14초 간격을 둡니다. 모든 효과음은 음표 버튼으로 함께 켜고 끕니다.

## 날씨와 수집 흔적

- 위쪽 ‘맑은 날 / 비 오는 날’ 버튼으로 날씨를 바꿉니다. 마지막 선택은 이 브라우저에 저장됩니다.
- 비 오는 날에는 빗줄기, 흐린 하늘, 물웅덩이와 잔물결이 나타납니다. 음표 버튼을 켜면 빗소리와 젖은 발자국 소리도 들립니다.
- 수집한 문장 종이는 벽에서 사라지고, 테이프와 옅은 종이 흔적만 남습니다. 흔적을 클릭하면 수집한 문장을 다시 읽을 수 있습니다.
- ‘처음으로’로 수집 기록을 초기화하면 종이도 원래대로 돌아옵니다. 날씨 선택은 유지됩니다.
- weather.js: 화면의 빗줄기 애니메이션.

## 시작 화면

처음 열면 실제 골목이 비치는 반투명 ‘거리에서 주운 문장’ 시작 화면이 나타납니다. ‘시작하기’로 산책에 들어가고, ‘프로젝트 설명’으로 작품 소개를 읽을 수 있습니다. 시작 화면에서는 이동 입력을 멈추며, 시작하기는 기존 문장집을 초기화하지 않습니다.

골목의 오토바이 3대에는 둥근 타이어·휠·앞 포크·펜더·거울·등화·배기통을 적용했습니다. 자전거도 3대 배치했으며, 프레임·바퀴살·체인·페달과 일부 앞바구니를 입체로 구성했습니다. 모두 흑백 선화로 표현됩니다.

바닥 소품 26개(오토바이·자전거·화분 묶음·상자·가스통)는 실제 모델의 외곽 크기로 배치 공간을 예약합니다. 다른 소품 및 고정 시설물과 겹치면 가까운 빈자리로 옮기고, 플레이어도 소품을 통과하지 못하도록 처리했습니다. 문장 종이 전체의 시야와 세 골목의 중앙 이동 경로를 함께 확인합니다.

시작 화면의 반투명 배경 뒤에서도 고양이·비둘기·구름과 빗물 잔물결은 계속 움직입니다. 시작하기 전에는 플레이어의 이동만 멈춥니다.

1번 문장은 사용자가 제공한 사진의 ‘인생은 인간이 철들만큼 길지 않다’입니다. 수집하면 실제 사진이 열리고, 사진 또는 주변 배경을 한 번 클릭하면 닫힙니다. 수집 흔적을 다시 클릭해 사진을 다시 볼 수 있습니다. 사진은 브라우저 호환을 위해 HEIC에서 JPEG로 변환하여 assets/sentence-01.jpg에 보관합니다.
